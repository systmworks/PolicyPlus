# Compiling Policy Plus
You can acquire the Policy Plus source code by cloning with [Git](https://git-scm.com/):

    git clone https://github.com/systmworks/PolicyPlus.git

It is recommended to set Git to ignore local changes to the autogenerated version files:

    git update-index --assume-unchanged PolicyPlus\Version.cs
    git update-index --assume-unchanged "PolicyPlus\My Project\AssemblyInfo.cs"

You can run `version.bat` at any time to regenerate those files: `Version.cs` gets your current
commit (shown in the app's About dialog), and `AssemblyInfo.cs`'s `AssemblyVersion`/
`AssemblyFileVersion` get updated to match the version at the top of `CHANGELOG.md`, so the
compiled EXE's Windows file properties always reflect the fork's actual current version. CI runs
this automatically on every push to `master` (see `.github/workflows/latest.yml`), so released
builds never need a manual version bump - only bumping the version in `CHANGELOG.md` itself.

Policy Plus is a C# WPF-UI (Fluent design) app targeting `net10.0-windows` (the [.NET 10 SDK](https://dotnet.microsoft.com/download) or later). You can build it with [Visual Studio 2022](https://visualstudio.microsoft.com/vs/community/) or later, or from the command line.

To compile in Visual Studio, open `PolicyPlus.sln` (from the `PolicyPlus` folder). Set the *Solution Configurations* dropdown to Release (or Debug for a debug build).
Choose *Build* | *Build PolicyPlus* from the main menu. The result is `PolicyPlus.exe`.
You can find that file in `PolicyPlus\bin\<Debug|Release>\net10.0-windows\`.

To compile from the command line:

    dotnet build PolicyPlus\PolicyPlus.sln -c Release

To run the automated tests (`PolicyPlus.Tests`):

    dotnet test PolicyPlus\PolicyPlus.Tests\PolicyPlus.Tests.csproj
